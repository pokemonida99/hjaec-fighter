# 紅分子 亮車快打（SHINE BRAWL）

復古像素風的「打車子」小遊戲，靈感來自街機格鬥遊戲的過關獎勵關，結合汽車美容品牌**紅分子 HJAEC**。

規則跟原版相反：原版是把車打爛，這裡是**把髒車打到發亮**。限時內用拳腳和必殺技把泥巴、灰塵、水斑、油膜、柏油和鳥屎打掉，亮度到 97% 就是 PERFECT SHINE。

線上玩：https://pokemonida99.github.io/hjaec-fighter/

## 玩法

- 四關：紅色轎車（車庫）→ 珍珠白休旅（夕陽洗車站）→ 曜石黑跑車（夜晚街頭）→ **飛天電動車（屋頂停機坪）**
- 最終關的飛天電動車洗到一點點就會起飛，在空中上下飄，要跳起來打；大約每 9 秒會降落充電一次，是追打的好機會
- 站著打車身中段，蹲著打下半部和輪圈（蹲拳、掃腿範圍比較大），跳起來打車頂；打中車子時泡沫水會往下流，也會洗到下面一點
- 走路有四格連續動作；連按兩下方向、或按住同方向約半秒就會開始跑，跑步中按拳直接衝刺連打
- 污泥怪會從輪子跑出來，碰到會被弄髒、短暫硬直；鴿子會在車頂上大便
- 打車會累積「紅分子能量」，集滿可以放超必殺「紅分子・全車鍍膜」：光波掃過的車身會鍍上一層膜
- 車子會跟著變乾淨起反應：30% 露出原色、60% 車燈亮起、85% 輪框閃光、完成時按喇叭閃燈
- 第三關剩 24 秒會下雨：沒鍍膜的地方會留下新的水斑，鍍過膜的地方雨水會彈開
- 標題畫面放著不動會輪播排行榜、電腦示範、開場動畫；破關分數進前五名可以輸入三個字的名字
- 暫停選單：繼續／出招表／重新開始這一關／回到標題／聲音開關；Android 手機打擊會震動
- 結算：清潔分數＋亮度＋剩餘時間（只有 PERFECT 才有）＋最大連擊＋趕走鴿子、打爆泥怪

## 版本與更新紀錄

目前版本寫在 `js/game.js` 的 `VERSION`，更新紀錄在同檔的 `CHANGELOG`（改版時兩個一起改）。遊戲裡看得到：標題畫面左下角有版本號，按 ↑ 進「更新紀錄」；電腦版桌墊右上角也有「更新紀錄」按鈕。

## 開場動畫與音樂

- **開場動畫（約 7 秒）**：紅分子品牌 → 四款商品（官方商品照）依序登場（奈米陶瓷封體鍍膜、超效除汙高泡洗車精、炫鑽玻璃鍍膜、全效環保去汙劑）→ 8 位角色斜切登場 → 一道光把髒車擦亮 → 標題落下。跟開場曲對拍，按任意鍵跳過。第一次打開要先點一下（瀏覽器規定要點擊才能出聲）。
- **待機循環**：標題 → 排行榜 → 電腦示範 → 開場動畫 → 標題（像街機一樣）。
- **配樂（全部原創、即時合成）**：開場曲、標題曲、選角曲（輕快 C 大調）、三首戰鬥曲（車庫＝A 小調搖滾、夕陽洗車站＝E 小調律動、夜晚街頭＝D 小調高速）、剩 10 秒的催促曲、結算曲、結局曲（溫暖 C 大調）。每首有主旋律、和聲、和弦琶音、貝斯、鼓。
- **音效**：開場的風聲與重擊、選角游標與決定音、每位角色的代表音（巨輪的低音和弦、水手的哨聲、小紅的噴霧聲、小芬的甩巾聲、小葵的水晶聲、小米的電話鈴、阿傑的重擊、VIVI 的飛吻）、結局煙火。

## 出招表（桌墊）

像街機台面上印的出招表：電腦版放在遊戲畫面正下方，列出基本操作和 8 位角色的指令，選角時會標出目前的角色（可以收起）；手機直拿放在畫面和按鍵中間，可以左右滑。遊戲中暫停選單也有「出招表」。

## 美術（v2.0）

比照街機格鬥遊戲的做法：角色是**一張張畫好的連續動作圖**，背景和車子也是整張繪製的像素圖。

- 角色：每人三張動作表（移動／普通攻擊／必殺），共 24 格，8 位角色共 192 格，用 GPT 依角色設定圖畫成 16-bit 像素風；`tools/slice.py` 自動去洋紅底、切格、對齊腳底、縮成約 74px 高，打包成 `js/sprite_data.js`
- 每位角色的必殺動作各不相同：栗子過肩丟結晶、小鈴對耳麥喊出音波、雷歐推鉛球式丟去汙球、蜜桃拋愛心；迴旋與連打也各有專屬動作
- 背景（車庫／夕陽洗車站／夜晚街頭）與三台車：`tools/stage_art.py` 轉成遊戲尺寸，打包成 `js/art_data.js`；招牌上的「紅分子」字樣是程式疊上去的
- 髒污仍是逐像素計算，但會跟車子原本的明暗混合，看起來像真的弄髒
- GPT 原圖與提示詞在 `work/`（只在本機）；重生某張圖：刪掉 `work/art/<名稱>.png` 後跑 `work/run_jobs.sh`

## 原創與授權說明

- **美術、程式、音樂、音效全部原創**：角色動作、背景、車子是為這款遊戲新畫的（GPT 依使用者的角色設定圖繪製，沒有使用任何既有遊戲的圖）；音樂與音效用 WebAudio 即時合成，沒有取樣任何既有遊戲的聲音。
- **沒有使用任何快打旋風的素材**（圖、音、字型、角色、名稱）。招式是「像但不一樣」的原創設計：

  | 這款遊戲 | 跟經典招式的差別 |
  |---|---|
  | 飛彈：單手「過肩拋投」丟出清潔道具（結晶、音波、去汙球、乳蠟愛心） | 不是雙掌前推的氣功；指令是 ↓↓＋拳，不是四分之一圓 |
  | 迴旋：手臂張開原地旋轉上升、甩出彩帶 | 不是上勾拳升天；指令是 ↓↓＋腳 |
  | 超必殺：頭像特寫＋一道鍍膜光波掃過整台車 | 是清潔效果，不是攻擊對手 |
- **角色外型**來自使用者提供的四張角色設定圖。頭像是用 GPT 依設定圖重繪成 16-bit 像素畫（髮型、服裝、眼鏡、耳麥照原設定，不另加配件），再縮成 64px／112px（`js/portraits.js`）；原圖與 GPT 原檔只留本機（`work/`），不放進 repo。名字、職業、台詞皆為原創。
- **字型**：俐方體 11 號（Cubic 11），授權見 `fonts/OFL.txt`，可商用、可隨遊戲散布。
- **飛天電動車**：外型參考現代流線型電動車，沒有任何車廠商標與名稱。
- **紅分子 HJAEC**：開場與每關結算的商品圖是紅分子官網（hjaec.com）的官方商品照（依使用者要求使用），只裁出瓶身、不含價格與促銷字（`tools/products.py`，原圖在 `work/official/`，只在本機）。

## 檔案

```
index.html          入口、觸控按鍵
js/core.js          畫布、像素文字、輸入（鍵盤／觸控／手把）
js/audio.js         合成音效與配樂
js/sprites.js       角色資料、姿勢、像素角色繪製、鴿子／泥怪
js/car.js           車子與逐像素污垢系統
js/stage.js         三關設定與背景
js/game.js          遊戲流程、招式、敵人、HUD
js/portraits.js     像素頭像（tools/portraits.py 產生）
tools/gen.sh        用 ChatGPT.app 的 codex 生圖（輸出到 work/art/）
tools/slice.py      切角色動作表 → js/sprite_data.js
tools/stage_art.py  背景與車子 → js/art_data.js
tools/portraits.py  把 work/art/p1~4.png 去白底、縮成遊戲用頭像
tools/bot.js        開發用：瀏覽器注入後可跑自動測試 bot、測平衡
```

改了 js 或 html 之後，把 `index.html` 裡所有 `?v=` 的數字一起加一，避免手機吃到舊快取。
